Paragraphs in HTML

This is a simple example demonstrating the use of paragraph tags (<p>) in HTML.

Paragraphs are used to structure and separate content in a webpage. They provide a clean and organized way to present text.

In HTML, you can use the <p> tag to define paragraphs. The content inside the <p> tag will be treated as a separate paragraph.

By default, browsers add some space above and below paragraphs, making the text more readable.
