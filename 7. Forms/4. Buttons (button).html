Button Example

  • The <button> element is used to create a clickable button within a form.
  • The type="button" attribute specifies a regular button (not submitting or resetting the form).
  • The onclick="alert('Button Clicked!')" attribute adds a JavaScript click event that shows an alert when the button is clicked.
  • The type="submit" attribute creates a button that submits the form when clicked.
  • The type="reset" attribute creates a button that resets the form's input fields to their default values when clicked.
  • The example includes buttons labeled "Click me," "Submit Form," and "Reset Form" within a form.
