Internal Links Example

This is a simple webpage demonstrating the use of internal links.

Section 1

This is the content of Section 1. You can navigate to Section 2 using the internal link below.

Click the following link to go to Section 2.

Section 2

This is the content of Section 2. You can navigate back to Section 1 using the internal link below.

Click the following link to go back to Section 1.

            The href="#section2" attribute in the first link creates an internal link that takes the user to the element with id="section2".
Similarly, the href="#section1" attribute in the second link takes the user back to the element with id="section1".
