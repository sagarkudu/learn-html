Table Structure Example

Header 1 Header 2 Header 3
Row 1, Cell 1 Row 1, Cell 2 Row 1, Cell 3
Row 2, Cell 1 Row 2, Cell 2 Row 2, Cell 3
Row 3, Cell 1 Row 3, Cell 2 Row 3, Cell 3
  • The <table> element is used to create a table.
  • The <thead> element contains the table header row, defined by <th> elements.
  • The <tbody> element contains the table body, defined by <tr> elements.
  • Within each row, data cells are represented by <td> elements.
  • Table headers are represented by <th> elements and are typically placed in the header row.
  • The border="1" attribute in the <table> tag adds a border to the table for better visibility.
