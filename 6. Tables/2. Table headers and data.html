Table Headers and Data Example

ID Name Age
1 John Doe 25
2 Jane Smith 30
3 Bob Johnson 22
  • The <thead> element contains the table header row, defined by <th> elements.
  • The <tbody> element contains the table body, defined by <tr> elements.
  • Table headers (column names) are represented by <th> elements and are placed in the header row.
  • Data cells within each row are represented by <td> elements.
  • In this example, the table represents information about individuals with columns for ID, Name, and Age.
